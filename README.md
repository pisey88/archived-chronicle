# 📜 Archived Chronicle

> Turn your daily calendar into a window through world history.

**Archived Chronicle** is an interactive historical platform that surfaces fascinating events, births, deaths, and holidays for any date in history — powered by the Wikimedia "On This Day" API.

---

## 🚀 Features

### Core Features
- **Today's Events** — Displays 3–5 major historical events from today's date on load
- **Time Travel Date Picker** — Enter any date to explore what happened on that day throughout history
- **Event Type Filter** — Toggle between Events, Births, Deaths, and Holidays
- **Full Summaries & Media** — Each event includes a description and Wikipedia imagery where available

### Interactive Features
- **Favorites System** — Save and revisit favorite historical events (persisted via `localStorage`)
- **Random Fact Cards** — Discover a random historical fact with a refresh button
- **Keyword Search** — Filter displayed events by searching for names, places, or topics

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Markup | HTML5 (semantic elements) |
| Styling | CSS3 + Bootstrap 5 |
| Logic | Vanilla JavaScript (ES6+) |
| Data | Wikimedia REST API |
| Storage | Browser `localStorage` |

> ⚠️ No JavaScript frameworks (React, Vue, Angular) are used — pure vanilla JS as per course requirements.
